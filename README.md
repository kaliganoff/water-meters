# Счётчики воды

Это приложение получает информацию о счётчиках воды и выводит её в виде таблицы с пагинацией и возможностью удаления.

## Используемые технологии

React, TypeScript, mox-state-tree

## Запуск проекта

1. `git clone https://github.com/kaliganoff/water-meters.git`
2. `npm i`
3. `npm run dev`
